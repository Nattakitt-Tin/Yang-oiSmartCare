# Yang-oiSmartCare — แบบประเมินสมดุลองค์รวม

คลินิกการแพทย์แผนไทย รพ.สต.บ้านยางอ้อย · https://yang-oismartcare.pages.dev/

เว็บแบบสอบถามประเมินสุขภาพตามหลัก **ธรรมนามัย ๓** (กายานามัย / จิตตานามัย / ชีวิตานามัย)
พร้อมรายงานวิเคราะห์ธาตุ ๔ บันทึกเป็น PDF ขนาด A4 หน้าเดียว และระบบหลังบ้านสำหรับเจ้าหน้าที่

รันบน **Cloudflare Pages + Functions + D1** ทั้งหมดอยู่ในโควตาฟรี

## โครงสร้าง

```
public/                 ← ไฟล์เว็บที่เสิร์ฟจริง
  index.html            หน้าคนไข้ ทำแบบประเมิน ไม่ต้องล็อกอิน
  admin/index.html      หน้าเจ้าหน้าที่ ต้องล็อกอิน (แดชบอร์ด · ผลการประเมิน · ตั้งค่า · ผู้ใช้)
  assets/core.js        ตรรกะคำนวณ ใช้ร่วมกันทั้งเบราว์เซอร์และเซิร์ฟเวอร์
  assets/sheet.js       สร้าง HTML รายงาน A4
  assets/editor.js      หน้าแก้ไขคำถามและผลลัพธ์
functions/api/          ← API (Cloudflare Pages Functions)
  config.js             GET  การตั้งค่าปัจจุบัน (สาธารณะ)
  submit.js             POST รับคำตอบ ออกเลขที่ บันทึกลง D1
  admin/*               ล็อกอิน สถิติ รายการผล ส่งออก CSV ตั้งค่า ผู้ใช้
migrations/             ← สคีมาฐานข้อมูล D1
apps-script/Code.gs     ← (ไม่บังคับ) ซิงก์ผลไป Google Sheet ควบคู่กันด้วย
```

## ฝั่งคนไข้ (`/`)

1. กรอกชื่อ เดือนเกิด (ธาตุเจ้าเรือนเติมให้อัตโนมัติ) และติ๊กยินยอมให้เก็บข้อมูล
2. ตอบคำถามทีละหมวด หมวดละหน้า ไม่แสดงคะแนนระหว่างทำ
3. ระบบออกเลขที่รายงาน `YA-YYMM-NNN` บันทึกลงฐานข้อมูล แล้วแสดงรายงาน → **บันทึกเป็น PDF / พิมพ์**

ถ้าเน็ตหลุด รายงานยังแสดงได้ (คำนวณในเครื่อง) และจะส่งเข้าระบบให้อัตโนมัติเมื่อเปิดหน้าเว็บครั้งถัดไป

## ฝั่งเจ้าหน้าที่ (`/admin/`)

| หน้า | ทำอะไรได้ | สิทธิ์ |
|---|---|---|
| แดชบอร์ด | จำนวนวันนี้/สัปดาห์/เดือน · สัดส่วนกลุ่มเสี่ยง · กราฟรายวัน · ค่าเฉลี่ยรายหมวดและธาตุ · ข้อที่พบปัญหาบ่อย | ทุกคน |
| ผลการประเมิน | ค้นชื่อ/รหัส กรองกลุ่มเสี่ยง/ช่วงวันที่ เปิดรายงานเดิม พิมพ์ PDF ซ้ำ ส่งออก CSV/Excel | ทุกคน (ลบได้เฉพาะผู้ดูแล) |
| ตั้งค่าแบบประเมิน | คำถาม เกณฑ์คะแนน การแปรผล ตารางกิจวัตร บริการ หัวรายงาน — บันทึกครั้งเดียวมีผลทุกเครื่อง | ผู้ดูแลระบบ |
| ผู้ใช้ | เพิ่ม/ลบ เปลี่ยนบทบาท รีเซ็ตรหัสผ่าน | ผู้ดูแลระบบ |

**เข้าครั้งแรก**: เปิด `/admin/` ระบบจะให้สร้างบัญชีผู้ดูแลระบบคนแรก (ทำได้ครั้งเดียวตอนยังไม่มีผู้ใช้)

ความปลอดภัย: รหัสผ่านเก็บแบบ PBKDF2 · คุกกี้ล็อกอินเซ็นด้วย HMAC หมดอายุ 12 ชม. · ล็อกอินผิด 5 ครั้งใน 15 นาทีจะถูกพัก · API ปฏิเสธคำขอข้ามเว็บไซต์

## Deploy (ครั้งแรก)

ต้องมีบัญชี Cloudflare (ฟรี) และ Node.js

```bash
npm install
npx wrangler login                                  # เปิดเบราว์เซอร์ให้อนุญาต
npx wrangler d1 create ttm-yangoi                   # คัดลอก database_id ที่ได้ไปใส่ใน wrangler.toml (ชื่อ DB ภายใน คงไว้ได้)
npx wrangler d1 migrations apply ttm-yangoi --remote
npx wrangler pages project create yang-oismartcare --production-branch main
npx wrangler pages secret put SESSION_SECRET --project-name yang-oismartcare   # ใส่ข้อความสุ่มยาวๆ เช่นจาก: openssl rand -hex 32
npm run deploy
```

ได้ URL `https://yang-oismartcare.pages.dev` แล้วเปิด `/admin/` เพื่อสร้างบัญชีแรก

**อัปเดตครั้งถัดไป**: แก้โค้ดแล้ว `npm run deploy` (ถ้าแก้ `migrations/` ให้รัน `npm run db:migrate` ก่อน)

### ซิงก์ไป Google Sheet ด้วย (ไม่บังคับ)
ติดตั้ง `apps-script/Code.gs` ตามคอมเมนต์ในไฟล์ แล้วตั้ง secret สองตัว:
```bash
npx wrangler pages secret put SHEET_URL --project-name yang-oismartcare      # URL ของ Web App ที่ลงท้าย /exec
npx wrangler pages secret put SHEET_SECRET --project-name yang-oismartcare   # ให้ตรงกับ SECRET ใน Code.gs
```
ทุกครั้งที่มีการประเมิน ระบบจะต่อท้ายชีตให้โดยไม่ทำให้คนไข้ต้องรอ

## พัฒนาในเครื่อง

```bash
npm install
npm run db:migrate:local
npm run dev            # http://localhost:8788
```

## หลักการประเมิน (สรุป)

- 9 ข้อ ข้อละ 0–3 → รวม 0–27 → กลุ่มเสี่ยง 0–9 / 10–18 / 19–27 (ตามชีตต้นฉบับ)
- คะแนนสมดุล 100 = `(27 − รวม) ÷ 27 × 100`
- รายหมวด: ≤38% สมดุลดี · ≤72% มาตรฐาน · >72% เฝ้าระวัง
- ธาตุ ๔ ผูกรายข้อ: ดิน 2,3 · น้ำ 5,8 · ลม 1,6,9 · ไฟ 4,7 → ≤24% ปกติ · ≤49% หย่อน · ≤74% กำเริบเล็กน้อย · >74% กำเริบ
- ทุกเกณฑ์แก้ได้ในหน้า ตั้งค่าแบบประเมิน

*รายงานนี้เป็นแนวทางดูแลสุขภาพเบื้องต้น ไม่ใช่การวินิจฉัยทางการแพทย์แผนปัจจุบัน*
